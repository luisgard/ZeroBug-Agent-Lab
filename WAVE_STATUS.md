## Known limits

- Fake apps only (store, outbox). No real purchases or email.
- One external framework tested, on localhost only.
- The heuristic judge only recognizes the phrases each scenario lists; anything else is INCONCLUSIVE by design.
- Observed results, not guarantees: N/N PASS does not predict the next run.
- UI is a minimal local page (no Next.js, no auth).

## What works now / partial / unsupported

- **Works now:** offline engine and verdicts, isolation, CLI, release gate, HTTP bridge with security controls, black-box mode with honest limits, an independent LangGraph agent tested end to end, minimal UI.
- **Partial:** UI stack (not Next.js), demo rehearsal, production hygiene (no deployment).
- **Unsupported / blocked:** real OpenAI Agents API and Decisions API runs (no key), other agent frameworks, browser and voice agents, public endpoints, automatic repair (AL-05, next wave).
